# 版本更新日志 (CHANGELOG)
 
## [V1.0.0] - 2026-05-24 (最后维护更新 2026-08-01)
### 芯片故障诊断模块前端展示精简 (Frontend UI Simplification)
- **移除“芯片故障诊断配置”原理展示模块**：按照业务需求将前端页面中的“芯片故障诊断配置”说明与原理卡片整体移除，精简界面呈现，让焦点专注在日志解析与管脚定位工具本身。

### 故障日志收集模块逻辑增强与视觉统一化 (Targeted Extraction Fixes)
- **目标到结束标识区间提取逻辑修正**：大幅优化目标命令关键词 + 结束命令关键词都不为空时的“指令区间提取”精确度。废除正则末行误伤匹配，改为通过模糊搜索特征准确识别结束条件，确保日志区间截取行为彻底回归设计预期（精准提取二者之间的日志内容，而非错误截取至文件末尾）。
- **统一异常反馈 UI 视觉规范**：在出现“有效配置目标指令为空，但缺失后续安全提示边界（结束匹配标签为空）”的异常断点时，错误警告模块现已对齐默认状态下的 `未在日志中找到任何匹配命令` 全大屏醒目红色告警（AlertCircle）视觉组件，实现全局消息样式范式大一统。
- **智能化缺少结束词探测**：新增对目标关键字存在的探测，如果用户只输入目标有效词，程序会自适应判断日志是否存在该词；若存在则提醒 `请输入结束命令关键词` 引导下一步；若不存在则回退至 `未在日志中找到任何匹配命令` 标准提示。

### 交换机日志设备型号提取器逻辑升级 (Product Model Extraction Upgrade)
- **引入 `syseeprom` 高优先级探测**：新增对 `ft-decode-syseeprom.py` 工具输出的专项解析适配，将设备型号提取优先级提升至最高。
- **精准字段定位**：优化针对 `Product Name` 行的特征提取算法，完美适配兼容 `Product Name 0x21 5 B4010` 类非标格式，确保型号字段（如 `B4010`）的 100% 准确抓取。
- **UI 布局优化**：精简“芯片故障诊断配置”交互界面，提炼关键信息标签，大幅度节省页面纵向占用空间，提升阅读效率。
### 芯片故障日志提取功能拓展与时间戳智能兼容性升级 (Timestamp Compatibility Expansion & Tracking)
- **多源点号时间戳解析支持**：全新兼容以点号 `.` 分隔的多级高精度硬件/固件日志时间戳格式，特别是完美支持带有毫秒级数据的中括号格式，如 `[2026.05.19 16:35:02.452]` 等非标格式。
- **自适应剥离技术**：在保持原始事件记录不被破坏的前提下，智能剔除、隔离以上时间戳前缀，完成高容错度命令行智能提取、命令关联与提示符特征预测。
- **更严谨的变化履历追踪**：在 `CHANGELOG.md` 中增加动态追踪记录块，无需升级主版本即可精确归档现场微调履历，确保对软件演进过程的 100% 颗粒度可核验性。

### 高价值芯片故障日志收集系统 - 首个生产级官方正式版发布 (Official Production Release)
- **正式版基线里程碑**：本系统作为集日志智能命令行提纯、特定异常文本自动捕获与底层硬件级寄存器、SerDes/PHY 链路训练（Link Training）综合诊断于一体的高端芯片排障平台，正式发布首个 `V1.0.0` 稳定版本。
- **页面版本号坚固锁定**：依据产品规范，前端界面版本标识彻底锚定为 `v1.0.0`；后续除非由用户指定下发升级命令，不再单方面调整前台主版本，而只进行底层逻辑与鲁棒性后台维护。
- **界面与性能优化收官**：
  - 彻底下线了不合现场规程的静态基本原理模块，使芯片诊断与管脚检索界面更为流畅、聚焦。
  - 重设了所有的面板交互动效，采用 `AnimatePresence` 消除一切列表展开闪烁，诊断大报告支持文件名深度个性化配置导出。
